# "Systems" DATAREF list for Shared Cockpit - which switches/radios/AP
# settings to mirror between both cockpits, per docs/plan.md section 6.
# One DATAREF line per dataref, # comments and blank lines ignored.
# Optional trailing tokens on a DATAREF line (any order):
#   OUTPUT             a result of the simulation, not a control (e.g.
#                       sim/flightmodel/engine/ENGN_running): only the
#                       pilot flying's value counts, the co-pilot just
#                       displays it.
#   STREAM             the pilot flying re-sends it every tick instead of
#                       only on change. Rarely needed.
#   CATEGORY <name>     engine, avionics or systems (default) - only groups
#                       the list.
# The pilot flying's cockpit is the reference for every value; a switch
# the co-pilot moves is sent there and applied. Yoke, pedals, toe brakes
# and throttle/mixture/prop levers are never listed here - they come from
# the pilot flying automatically.
#
# COMMAND <command> lines mirror a button press into the other cockpit
# (autopilot modes, a starter key that has to be held, ...).
#
# ROLE (MASTER/CLIENT) and peer discovery are NOT set here - Shared
# Cockpit always starts through the companion app, which handles that via
# the rendezvous server (session code, no manually-typed peer address).
# This file only ever supplies the DATAREF list for that session.
#
# Copy this file to "XPMultiCrew_shared_cockpit.txt" next to where you
# start X-Plane from (its working directory), or point the plugin at it
# via the XPMULTICREW_SHARED_COCKPIT_FILE environment variable - only
# needed for an aircraft without a per-aircraft profile already covering
# it (see XPMultiCrew_shared_cockpit_profiles/<ICAO type>.txt and the
# plugin-bundled default profiles, e.g. C172 - root README's
# ResolveSharedCockpitConfigPath section has the full lookup order).
#
# Both of you must be flying the SAME aircraft - position/attitude sync
# and the generic dataref sync both assume that.

DATAREF sim/cockpit2/radios/actuators/com1_frequency_hz
DATAREF sim/cockpit/radios/transponder_code
DATAREF sim/cockpit2/autopilot/heading_dial_deg_mag_pilot
DATAREF sim/flightmodel/controls/parkbrake

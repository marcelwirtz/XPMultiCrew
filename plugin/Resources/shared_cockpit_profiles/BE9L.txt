# Shared Cockpit "systems" dataref list for the default X-Plane 12
# Beechcraft King Air C90B (ICAO type "BE9L", twin PT6 turboprop,
# retractable gear) - see shared_cockpit/shared_cockpit_config.h's
# ResolveSharedCockpitConfigPath: this file is picked up automatically
# whenever the current aircraft's ICAO type matches this filename.
#
# Every dataref below was checked against a real X-Plane 12
# Resources/plugins/DataRefs.txt, not guessed - see C172.txt's header
# comment for the general ground rules (writable-only, no autopilot-mode-
# engagement datarefs) and BE58.txt's header comment for why per-engine
# array datarefs (not the "_all" variants) are used throughout - both
# still apply here.
#
# Turboprop-specific differences from BE58.txt (piston twin):
#   - No carb_heat_ratio/primer_on - turbine engines have neither a
#     carburetor nor a primer, and X-Plane doesn't expose either dataref
#     as meaningful for this engine type.
#   - mixture_ratio (per-engine, 0.0=cutoff..1.0=full rich for a piston
#     engine) is the SAME dataref X-Plane's generic engine model reuses
#     for a turboprop's condition lever - there's no separate
#     "condition_lever" dataref in X-Plane's data model. Synced here
#     unchanged; the doc string's piston-specific wording just doesn't
#     apply literally.
#   - ENGN_propmode is added: the PT6's prop can be feathered or run in
#     beta/reverse range for ground ops, which a fixed-pitch or simple
#     constant-speed piston prop (BE58.txt) doesn't model.

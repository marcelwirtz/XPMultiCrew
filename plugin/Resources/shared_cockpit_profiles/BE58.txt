# Shared Cockpit "systems" dataref list for the default X-Plane 12
# Beechcraft Baron 58 (ICAO type "BE58", twin piston, constant-speed props,
# retractable gear) - see shared_cockpit/shared_cockpit_config.h's
# ResolveSharedCockpitConfigPath: this file is picked up automatically
# whenever the current aircraft's ICAO type matches this filename.
#
# Every dataref below was checked against a real X-Plane 12
# Resources/plugins/DataRefs.txt, not guessed - see plugin/Resources/
# shared_cockpit_profiles/C172.txt's header comment for the general
# ground rules this follows (writable-only, no autopilot-mode-engagement
# datarefs, etc.), all still true here.
#
# Twin-specific difference from C172.txt worth calling out explicitly:
# the per-engine handle datarefs below (throttle_ratio, prop_ratio,
# mixture_ratio, ...) are deliberately NOT the "_all" variants C172.txt
# uses (throttle_ratio_all etc.) - those move every engine's handle
# together as one, which is exactly wrong for a twin: the 3D cockpit's two
# separate throttle/prop/mixture levers are bound to these per-engine
# array datarefs, and syncing the "_all" scalar instead would fight
# independent per-engine handle positions (e.g. a deliberately asymmetric
# power setting) instead of reproducing them. For a single-engine
# aircraft like the C172 the distinction is moot (only one engine to
# move), which is why that profile could get away with the simpler "_all"
# form.

# Shared Cockpit "systems" dataref list for the default X-Plane 12
# Beechcraft Baron 58 (ICAO type "BE58", twin piston, constant-speed props,
# retractable gear) - see shared_cockpit/shared_cockpit_config.h's
# ResolveSharedCockpitConfigPath: this file is picked up automatically
# whenever the current aircraft's ICAO type matches this filename.
#
# Every dataref below was checked against a real X-Plane 12
# Resources/plugins/DataRefs.txt, not guessed - see plugin/Resources/
# shared_cockpit_profiles/C172.txt's header comment for the general
# ground rules this follows (writable-only, no autopilot-mode-engagement
# datarefs, etc.), all still true here.
#
# Throttle, prop and mixture levers (per engine) aren't listed: like the
# yoke they come from the pilot flying as a stream - see C172.txt's header.
# The key switches and fuel selectors are COMMANDs (end of file), for the
# same reason as the C172's key: the starter has to be held, which a
# written dataref can't do.

# Radios - active and standby, so a flip/flop swap either pilot makes
# shows up correctly on both sides, not just the currently-active side
DATAREF sim/cockpit2/radios/actuators/com1_frequency_hz CATEGORY avionics
DATAREF sim/cockpit2/radios/actuators/com1_standby_frequency_hz CATEGORY avionics
DATAREF sim/cockpit2/radios/actuators/com2_frequency_hz CATEGORY avionics
DATAREF sim/cockpit2/radios/actuators/com2_standby_frequency_hz CATEGORY avionics
